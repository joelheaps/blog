# Projects
These are projects I'm working on, if only occasionally:

## NWS Notifier

[NWS Notifier](https://github.com/joelheaps/nws-notifier) is a simple little Python app that can send alerts about forecast discussions posted by the National Weather Service and the Storm Prediction Center.  Right now Discord is my chosen notification target.  I recently added a static-site generator with map plotting functionality to make alert links more useful.

## Convective.app

Unlaunched, at the moment. Convective.app is a website that can issue alerts when storms approach, and serves a useful map frontend so help gauge storm risk.  

## KMEY.info

[KMEY.info](https://kmey.info) is a simple weather dashboard for my local airport, optimized to load over a slow connection.  MEY, or James Whiting Memorial Field of Mapleton, IA, doesn't have automatic weather observation equipment like other small airports, and has only a basic internet connectivity.  This page scrapes and pre-processes local weather data and presents a little landing page for airport info.
